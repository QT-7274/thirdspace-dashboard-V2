# 项目中心看板设计规格

日期：2026-08-02  
状态：待用户确认  
范围：ThirdSpace Dashboard V2 的项目聚合、Todo 项目维度和看板布局

## 1. 背景

当前看板按数据来源拆分内容：今日 Todo、昨日遗留、项目灵感、WORK TODOS、ACAI 和 PRODUCTS 分别占用独立区域。同一个项目的任务、灵感和实现进度因此分散在不同位置。

当前“昨日遗留”面板还会把前一天未完成的任务复制到今日工作日志，但不会修改来源日志。这个行为符合历史日志保留原则，却不符合用户对“加入今日后完成原任务”的直觉，容易产生重复任务和状态分裂。

本设计把项目作为看板的聚合维度，同时保留 Todo 的时间视图。项目视图与时间视图读取和修改同一条任务数据，不创建副本。

## 2. 目标与边界

### 目标

- 用项目卡片聚合相关 Todo、项目灵感和 ACAI 进度。
- 让 Todo 可以手动选择项目，也可以按项目筛选。
- 让项目名称由项目主表统一管理，避免同名项目重复出现。
- 保留 `TODAY'S TODOS`、逾期任务和 `UPCOMING TASKS` 的执行视图。
- 删除重复或分散的独立面板，降低看板扫描成本。
- 兼容已有 Todo、灵感文件、ACAI 设置和历史工作日志。

### 非目标

- 不把历史工作日志迁移成项目文件。
- 不自动重写已有 Markdown 的项目名称或标签。
- 不改变 ACAI 服务的 API 或状态模型。
- 不把一个 Todo 拆成多个项目任务。
- 不在本次工作中重做工作区、Activity 或 Recent 的数据模型。

## 3. 已确认的产品决策

1. 删除“昨日遗留”面板。删除只影响面板展示，不修改历史工作日志。
2. `04-项目/product-status.md` 是项目主表。
3. Todo 使用 `#project/<projectId>` 保存项目归属。
4. Todo 面板同时提供项目归属选择和项目筛选。
5. Todo 继续出现在时间视图；项目卡片展示同一条 Todo 的项目视图。
6. 项目列表默认折叠，同一时间只展开一个项目。
7. 项目卡片聚合 Todo、灵感和 ACAI；ACAI 只在项目展开时加载。
8. 删除独立的项目灵感、WORK TODOS、ACAI 和 PRODUCTS 面板。
9. QUICK 中的“搜索”按钮替换为“记灵感”。Obsidian 原生搜索入口保持可用。
10. 旧数据采用兼容读取，不做自动批量迁移。

## 4. 项目标识与主表

项目由稳定的 `projectId` 和可变的展示名称组成。`projectId` 只使用小写字母、数字和连字符，展示名称可包含中文和空格。

建议的 `product-status.md` 项目段落如下：

```md
## 🟢 进行中

### ThirdSpace Dashboard
- 项目标识：thirdspace-dashboard
- ACAI Product：thirdspace-dashboard
- 当前里程碑：完成项目中心改版
```

字段定义：

| 字段 | 作用 | 必填 |
| --- | --- | --- |
| 项目标题 | UI 展示名称 | 是 |
| 项目标识 | Todo 和灵感的稳定关联键 | 是 |
| ACAI Product | ACAI API 使用的产品名 | 否，缺省使用项目标识 |
| 当前里程碑 | 项目卡片摘要 | 否 |
| 所属状态段 | active、watch 或 paused | 是 |

读取器需要向后兼容当前没有项目字段的项目段落：此时用规范化后的项目标题生成临时 ID，仅用于显示和读取；新建或编辑项目关系时要求主表提供稳定项目标识。

## 5. 数据格式与关联规则

### 5.1 Todo

项目 Todo 使用普通 Obsidian 标签保存项目关系：

```md
- [ ] 实现项目中心 #project/thirdspace-dashboard #工作 ^ts-abc123
```

规则：

- `#project/<projectId>` 只允许一个；后出现的合法项目标签覆盖前一个，界面提示格式异常。
- `#project/...` 从普通标签列表中单独解析，不重复显示为普通标签 chip。
- `#工作` 等其他标签继续保留原语义。
- 没有项目标签的任务属于“未归属”。
- 通过稳定 `taskId` 修改项目关系，避免用任务文本匹配同名任务。

### 5.2 项目灵感

现有灵感文件继续使用 Markdown。新的灵感分组使用 `projectId` 作为二级标题：

```md
## thirdspace-dashboard

- [💡] 2026-08-02 14:30 · 项目卡片支持折叠 ^pi-abc123
```

读取器同时接受现有的展示名称标题，并通过项目主表的展示名称、`projectId` 和 ACAI Product 做兼容匹配。新建灵感优先写入已有匹配分组；没有匹配分组时写入 `projectId` 分组。

### 5.3 ACAI

项目卡片通过项目主表的 `ACAI Product` 查询 ACAI。未配置该字段时使用 `projectId`。ACAI 的 feature 和 ACID 状态继续由现有 ACAI API 管理。

### 5.4 未登记数据

Todo、灵感或 ACAI 出现项目关系但无法匹配项目主表时，归入“未登记项目”分组。该分组显示原始名称和数据，不自动创建项目，也不改变源文件。

## 6. 看板结构

### 6.1 页面层级

```text
统计 / Activity
今日执行区
├─ TODAY'S TODOS
├─ TODAY
└─ QUICK
PROJECTS
辅助信息
├─ 逾期任务
├─ UPCOMING TASKS
├─ WORKSPACES
└─ RECENT
```

项目中心使用全宽区域，避免 ACAI 内容受右栏宽度限制。项目卡片按项目主表顺序展示，未登记项目固定在末尾。

### 6.2 项目摘要卡片

折叠状态显示：

- 状态标识
- 项目展示名称
- 当前里程碑
- 未完成 Todo 数量
- 未放弃灵感数量
- ACAI 汇总进度；尚未加载时显示待加载状态

点击项目标题或折叠按钮展开项目。展开一个项目时关闭其他项目，刷新后保留当前展开项目。

### 6.3 展开内容

```text
项目标题与摘要
├─ TODO                 INSPIRATIONS
│  ├─ 未完成任务          ├─ 最近灵感
│  └─ 添加任务            └─ 记灵感
└─ ACAI
   ├─ 总体进度
   └─ 可展开的 feature / ACID
```

桌面宽度下 Todo 与灵感并排，ACAI 占整行。窄屏下三部分改为纵向排列。默认只显示未完成 Todo 和未放弃灵感；已有的灵感状态切换、行内编辑、删除确认、ACAI feature 展开和 ACID 状态编辑继续可用。

## 7. Todo 交互

### 7.1 项目筛选

`TODAY'S TODOS`、`UPCOMING TASKS` 和项目内 Todo 区域提供项目筛选。筛选项包括：

- 全部项目
- 未归属
- 项目主表中的项目

筛选只影响当前显示，不修改任务数据。筛选状态只在当前看板会话中保存。

### 7.2 项目归属编辑

Todo 行显示项目 chip：

```text
☐ 实现项目中心       [ThirdSpace Dashboard ▾]  #工作
☐ 整理临时笔记       [+ 选择项目]
```

点击 chip 打开项目选择器。选择项目后写入 `#project/<projectId>`；选择“无项目”时移除该标签。当前筛选具体项目时，新建 Todo 默认使用该项目；没有筛选时新建 Todo 默认未归属。

### 7.3 同步写入

- 有 `taskId` 的任务：先修改任务池，再同步今日工作日志中的同一任务。
- 只有今日工作日志记录的任务：只修改今日工作日志。
- 同步任一步失败时显示错误通知，重新读取源文件并恢复界面状态。
- 项目中心与时间视图只引用解析结果，不写入第二份任务。

## 8. QUICK 与灵感入口

QUICK 保留“新笔记”“今日志”“记TODO”“收件箱”，将“搜索”替换为“记灵感”。“记灵感”打开现有灵感弹框，项目选项来自项目主表；若项目中心当前展开，则默认选中当前项目。

## 9. 删除与保留范围

### 删除

- “昨日遗留”卡片及其入口。
- 独立的“项目灵感”卡片。
- 独立的 `WORK TODOS` 卡片。
- 独立的 ACAI 卡片。
- 独立的 PRODUCTS 卡片；产品状态和里程碑进入项目标题摘要。

### 保留

- `TODAY'S TODOS`、逾期任务和 `UPCOMING TASKS`。
- `#工作` 标签和工作任务的标签显示。
- 今日工作日志和历史工作日志原文件。
- 项目灵感的状态、编辑、删除能力。
- ACAI feature、ACID 展开和状态编辑能力。
- Workspaces、Recent、Activity 等非项目区域。

## 10. 性能与失败处理

- 首次渲染先加载本地项目、Todo 和灵感数据，项目卡片摘要不等待 ACAI。
- 只有展开项目时才请求该项目 ACAI 数据。
- 同一项目的进行中 ACAI 请求复用现有 Promise，缓存沿用现有 TTL。
- 单个项目 ACAI 失败只影响该项目，并提供重试入口；其他项目继续可用。
- `product-status.md` 不存在时仍显示现有任务和灵感，但项目选择器只提供“未归属”，未登记数据仍可查看。
- 写入失败时不保留乐观 UI 状态，显示 `Notice` 并重新读取相关区域。
- ACAI 认证失败、服务不可用和空数据使用不同提示，不阻塞本地 Todo 操作。

## 11. 兼容与迁移

- 不修改历史工作日志，不把“加入今日”改成自动完成历史任务。
- 没有 `#project/...` 的旧 Todo 显示在“未归属”，可以在 Todo 行直接补充项目。
- 旧灵感项目标题按显示名称兼容读取；用户编辑后才逐步写入规范分组。
- 旧 ACAI 设置不变，项目主表只增加可选映射字段。
- 首次上线不执行批量 Markdown 改写，避免用户文件产生不可逆噪音。

## 12. 测试与验收

### 数据层

- 解析、规范化和校验 `projectId`。
- 解析单个项目标签、无项目标签和异常重复标签。
- 项目主表读取、状态和里程碑解析、旧格式兼容。
- 灵感按 `projectId`、展示名称和 ACAI Product 的匹配。
- Todo 项目修改在任务池和今日工作日志之间正确同步。

### 视图层

- 项目卡片摘要计数正确。
- 项目展开只显示一个项目，刷新后恢复展开状态。
- 项目筛选的全部、未归属和具体项目结果正确。
- Todo 项目选择器、移除项目和当前筛选默认值正确。
- QUICK 中“记灵感”替代“搜索”。
- 独立旧面板不再渲染。
- ACAI 只在展开项目时加载，单项目失败不影响其他项目。
- 桌面和窄屏布局无内容遮挡或溢出。

### 回归

- Todo 完成、删除、编辑、逾期排序和分页继续工作。
- 灵感状态切换、双击编辑和删除继续工作。
- ACAI feature 展开和 ACID 状态写回继续工作。
- `npm run build` 通过，并将 build 产物复制到 `/Users/shizheng/Documents/BlinkLLMWiki-Release-v1.0/.obsidian/plugins/thirdspace-dashboard`。

## 13. 计划中的代码边界

- `src/data/vault-reader.ts`：项目主表、项目标签和灵感关联解析与写入。
- `src/view.ts`：Todo 项目选择/筛选、项目中心、ACAI 懒加载和旧面板移除。
- `src/styles.css`：项目中心全宽布局、项目卡片、响应式和筛选控件。
- `tests/`：数据解析、同步写入、视图契约和回归测试。
- `features/thirdspace/`：新增或更新 ACID 需求，保持描述和 requirement 使用简体中文。
